# 💈 Barber Shop Landing Page

A modern, responsive landing page for a barbershop, built to showcase services, pricing, and contact details.

## 🚀 Live Demo
See the [live demo](https://barber-landing-page-kappa.vercel.app)

## 🛠️ Built With
- **HTML5** – Semantic structure
- **CSS3** – Modern layout & styling (Flexbox / Grid)
- **JavaScript** – Interactive elements

## ✨ Features
- Fully responsive design (Mobile & Desktop)
- Clean and readable service menu with pricing
- Call-to-action (CTA) button for quick booking/contact
- Location and business hours section
